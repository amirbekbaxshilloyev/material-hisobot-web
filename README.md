# Material Hisobot — veb sahifalar

Telegram-bot [Material Hisobot](https://t.me/material_reportbot) uchun ochiq sahifalar (GitHub Pages):

- [`maxfiylik/`](https://amirbekbaxshilloyev.github.io/material-hisobot-web/maxfiylik/) — maxfiylik siyosati. Bot egasi uni Telegram ichida veb-ilova sifatida ochadi, oxirigacha o‘qib tasdiqlaydi.

Fayllar qo‘lda tahrirlanmaydi: asosiy loyihada `npm run privacy:publish` ularni yaratadi va shu yerga yuklaydi.
